# Sales-Data-Analysis--Python
An end-to-end sales data analysis project using Python, Pandas, NumPy, Matplotlib and Seaborn to clean, analyze and visualize customer, sales, product, demographic and regional data to generate actionable business insights.

Technologies / modules section-

Tools & Technologies:
- Python
- Pandas — data manipulation and analysis
- NumPy — numerical operations
- Matplotlib — data visualization
- Seaborn — statistical visualization
- Jupyter Notebook
- Excel — source data
- CSV — exported analytical data

Skills demonstrated:
- Data Cleaning

My project covers:

Data Loading
- Imported sales data from Excel using Pandas.
- Dataset contains 11,251 records and 15 columns before cleaning.
- Customer, product, gender, age, marital status, state, zone, sector, product category, orders and amount information.

Data Cleaning
- Checked missing values.
- Renamed Occupation → Sector.
- Converted Marital_Status values into meaningful labels.
- Removed completely empty Status and unnamed1 columns.
- Removed rows containing null values.

Exploratory Data Analysis
- Unique states
- Unique zones
- Unique product categories
- Unique sectors
- Age groups
- Gender
- State-wise orders
- Zone-wise sales amount
- Sector-wise orders
- Product-category analysis
also exported unique States, Zones, Products and Sectors into CSV files.
